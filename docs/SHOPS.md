# 쇼핑몰별 CPS(구매당 수수료) 현황과 봇 지원 범위

2026년 9월 기준으로 조사한 내용입니다. 수수료율과 정책은 자주 바뀌니 가입 전 각 사이트에서 다시 확인하세요.

## 국내 구매 규모 순 (대략) 과 CPS 제공 여부

거래액 기준 1위 쿠팡(약 22.8%), 2위 네이버플러스 스토어(약 20.7%)는 조사 데이터가 있고, 그 아래는 결제추정액·이용자 수 자료를 종합한 대략적인 순서입니다.

| 순위 | 쇼핑몰 | CPS 프로그램 | 수수료(대략) | 링크 생성 방식 | 봇에서의 처리 |
|---|---|---|---|---|---|
| 1 | 쿠팡 | 쿠팡 파트너스 | 3% | **API** (딥링크) | 완전 자동 |
| 2 | 네이버 (스마트스토어/플러스스토어) | 네이버 쇼핑커넥트 | 직접 3~50%(판매자 설정), 간접 1.8% | 사이트에서 수동 | 반자동 (봇이 알려주면 내가 링크 만들어 답장) |
| 3 | 알리익스프레스 | 알리 어필리에이트 / 링크프라이스 | 1~7% | API (Portals) / 링크프라이스 API | 링크프라이스 ID 있으면 자동 |
| 4 | 테무 | 테무 어필리에이트 (신규 유입 중심) | 최대 20% + 신규 설치 보너스 | 앱에서 수동 | 원본 링크(수익 없음) 또는 제외 |
| 5 | 11번가 | 링크프라이스 / 애드픽 | 1~10% (머천트별) | 네트워크 API | 링크프라이스 ID 있으면 자동 |
| 6 | G마켓 / 옥션 | 링크프라이스 / 애드픽 | 1~10% | 네트워크 API | 링크프라이스 ID 있으면 자동 |
| 7 | 무신사 | 무신사 큐레이터 | 비공개(등급별) | 앱에서 수동 | 반자동 |
| 8 | 올리브영 | 올리브영 쇼핑 큐레이터 | 추천 상품 7%, 그 외 3% | 앱에서 수동, 심사 없음 | 반자동 |
| 9 | 컬리 | 컬리 큐레이터 | 등급별 차등 | 앱에서 수동 | 반자동 |
| 10 | SSG / 롯데온 | 링크프라이스 | 1~10% | 네트워크 API | 링크프라이스 ID 있으면 자동 |
| 11 | 토스쇼핑 | 토스쇼핑 쉐어링크 | 10% (프로모션 기간, 클릭 후 24시간 내 전체 구매) | **앱에서만** 수동 | 반자동 |
| 12 | 다이소몰 | 없음(확인 못 함) | - | - | 원본 링크 |
| 13 | 오늘의집 | 링크프라이스 | 머천트별 | 네트워크 API | 링크프라이스 ID 있으면 자동 |

- 예약당 수수료(아고다, 부킹닷컴 등)는 요청대로 제외했습니다.
- 당근, 배민은 이용자 수는 많지만 상품 CPS 가 없어 제외했습니다.
- "반자동": 봇이 커뮤니티에서 딜을 찾아 관리자 챗으로 "링크 필요 #번호" 알림을 보내고, 내가 앱에서 링크를 만들어 답장하면 봇이 발행합니다. 링크를 못 만드는 쇼핑몰은 `link_mode: raw` 로 바꾸면 원본 링크로 자동 발행됩니다(수익 없음).

## 링크프라이스 · 알리 · 쇼핑커넥트를 "합칠" 수 있나

- **하나의 계정으로 합칠 수는 없습니다.** 세 곳은 서로 다른 회사의 프로그램이고, 각각 가입·승인·정산이 따로입니다.
- **봇 안에서는 합쳐집니다.** 쇼핑몰마다 링크 변환기를 두는 구조라, 설정만 하면 한 파이프라인에서 쿠팡(API) + 링크프라이스(11번가/G마켓/알리 등) + 수동(토스/네이버)이 같이 돌아갑니다.
- 알리익스프레스는 링크프라이스 머천트에도 들어 있어, 링크프라이스 ID 하나로 11번가·G마켓과 함께 처리하는 게 간단합니다. 알리 자체 어필리에이트(Portals API)는 수수료가 더 높을 수 있어 나중에 추가 연동 가능합니다.
- 네이버 쇼핑커넥트는 API 가 없어 어느 네트워크로도 자동화가 안 됩니다. 네이버 딜은 "반자동" 이 최선입니다.

## 수집원

| 수집기 | 대상 | 상태 |
|---|---|---|
| `coupang_goldbox`, `coupang_category_best` | 쿠팡 API | 구현 완료 (키 필요) |
| `ppomppu` | 뽐뿌 핫딜 게시판 — 쿠팡/토스/네이버/11번가/G마켓/알리/올리브영/컬리… 태그 전부 | 구현 완료 (실제 HTML 로 검증 필요) |
| `adpick_hotdeal` | 애드픽 쇼핑메이트 핫딜 JSON API (여러 몰의 핫딜 + 내 제휴 링크) | 구현 (응답 필드는 가입 후 확인) |
| 관리자 직접 입력 (`/post`) | 토스 앱에서 본 특가 등 | 구현 완료 |

토스쇼핑은 앱 전용이라 "토스 앱 안의 특가 목록"을 직접 크롤링하는 방법이 없습니다. 대신 뽐뿌·루리웹 같은 커뮤니티에 올라오는 `[토스쇼핑]` 글을 수집하고, 내가 앱에서 쉐어링크를 만들어 붙이는 방식입니다.

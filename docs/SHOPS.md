# 쇼핑몰별 CPS(구매당 수수료) 현황과 봇 지원 범위

2026년 9월 기준으로 조사한 내용입니다. 수수료율과 정책은 자주 바뀌니 가입 전 각 사이트에서 다시 확인하세요.

## 국내 구매 규모 순 (대략) 과 CPS 제공 여부

거래액 기준 1위 쿠팡(약 22.8%), 2위 네이버플러스 스토어(약 20.7%)는 조사 데이터가 있고, 그 아래는 결제추정액·이용자 수 자료를 종합한 대략적인 순서입니다.

| 순위 | 쇼핑몰 | CPS 프로그램 | 수수료(대략) | 링크 생성 방식 | 봇에서의 처리 |
|---|---|---|---|---|---|
| 1 | 쿠팡 | 쿠팡 파트너스 | 3% | **API** (딥링크) | 완전 자동 |
| 2 | 네이버 (스마트스토어/플러스스토어) | 네이버 쇼핑커넥트 | 직접 3~50%(판매자 설정), 간접 1.8% | 사이트에서 수동 | 반자동 (봇이 알려주면 내가 링크 만들어 답장) |
| 3 | 알리익스프레스 | 알리 어필리에이트 / 링크프라이스 | 1~7% | API (Portals) / 링크프라이스 API | 링크프라이스 ID 있으면 자동 |
| 4 | 테무 | 테무 어필리에이트 (신규 유입 중심) | 최대 20% + 신규 설치 보너스 | 앱에서 수동 | 원본 링크(수익 없음) 또는 제외 |
| 5 | 11번가 | 링크프라이스 / 애드픽 | 1~10% (머천트별) | 네트워크 API | 링크프라이스 ID 있으면 자동 |
| 6 | G마켓 / 옥션 | 링크프라이스 / 애드픽 | 1~10% | 네트워크 API | 링크프라이스 ID 있으면 자동 |
| 7 | 무신사 | 무신사 큐레이터 | 비공개(등급별) | 앱에서 수동 | 반자동 |
| 8 | 올리브영 | 올리브영 쇼핑 큐레이터 | 추천 상품 7%, 그 외 3% | 앱에서 수동, 심사 없음 | 반자동 |
| 9 | 컬리 | 컬리 큐레이터 | 등급별 차등 | 앱에서 수동 | 반자동 |
| 10 | SSG / 롯데온 | 링크프라이스 | 1~10% | 네트워크 API | 링크프라이스 ID 있으면 자동 |
| 11 | 토스쇼핑 | 토스쇼핑 쉐어링크 | 10% (프로모션 기간, 클릭 후 24시간 내 전체 구매) | **앱에서만** 수동 | 반자동 |
| 12 | 다이소몰 | 없음(확인 못 함) | - | - | 원본 링크 |
| 13 | 오늘의집 | 링크프라이스 | 머천트별 | 네트워크 API | 링크프라이스 ID 있으면 자동 |
| 14 | CJ더마켓 (햇반·스팸·비비고 등 식품) | 링크프라이스 | 머천트별 | 네트워크 API | 링크프라이스 ID 있으면 자동 |
| 15 | 현대Hmall / 롯데홈쇼핑 / GS SHOP | 링크프라이스 | 머천트별 | 네트워크 API | 링크프라이스 ID 있으면 자동 (홈쇼핑 식품·생활용품 특가) |
| 16 | 아이허브 | 링크프라이스 | 머천트별 | 네트워크 API | 링크프라이스 ID 있으면 자동 |

- **기본으로 켜진 몰 (2026-09 결정)**: 쿠팡, 토스쇼핑, 네이버. 수수료가 작거나 특가가 드문 몰은 조사에서 빼되, API 로 링크가 자동 발급되는 몰은 포함한다는 원칙입니다.
  링크프라이스 그룹(11번가, G마켓, 옥션, SSG, 롯데온, 알리, 오늘의집, CJ더마켓, 현대Hmall, 롯데홈쇼핑, GS SHOP, 아이허브)은 `LINKPRICE_AFFILIATE_ID` 가 있을 때만 자동으로 켜지고, 올리브영·컬리·무신사(앱에서만 링크 생성)와 테무·다이소(수익 없음)는 기본 꺼짐입니다. `config.yaml` 의 `shops:` 에 한 줄로 다시 켤 수 있습니다.
- 예약당 수수료(아고다, 부킹닷컴 등)는 요청대로 제외했습니다.
- 당근, 배민은 이용자 수는 많지만 상품 CPS 가 없어 제외했습니다.
- "반자동": 봇이 커뮤니티에서 딜을 찾아 관리자 챗으로 "링크 필요 #번호" 알림을 보내고, 내가 앱에서 링크를 만들어 답장하면 봇이 발행합니다. 링크를 못 만드는 쇼핑몰은 `link_mode: raw` 로 바꾸면 원본 링크로 자동 발행됩니다(수익 없음).

## 링크프라이스 · 알리 · 쇼핑커넥트를 "합칠" 수 있나

- **하나의 계정으로 합칠 수는 없습니다.** 세 곳은 서로 다른 회사의 프로그램이고, 각각 가입·승인·정산이 따로입니다.
- **봇 안에서는 합쳐집니다.** 쇼핑몰마다 링크 변환기를 두는 구조라, 설정만 하면 한 파이프라인에서 쿠팡(API) + 링크프라이스(11번가/G마켓/알리 등) + 수동(토스/네이버)이 같이 돌아갑니다.
- 알리익스프레스는 링크프라이스 머천트에도 들어 있어, 링크프라이스 ID 하나로 11번가·G마켓과 함께 처리하는 게 간단합니다. 알리 자체 어필리에이트(Portals API)는 수수료가 더 높을 수 있어 나중에 추가 연동 가능합니다.
- 네이버 쇼핑커넥트는 API 가 없어 어느 네트워크로도 자동화가 안 됩니다. 네이버 딜은 "반자동" 이 최선입니다.

## 핫딜 채널들은 어디서 딜을 가져오나

직접 쇼핑몰을 뒤지는 채널은 거의 없습니다. 대부분 아래를 조합합니다.

1. **커뮤니티 핫딜 게시판**: 뽐뿌(가장 큼), 루리웹 핫딜, 클리앙 알뜰구매, 퀘이사존, 어미새, 딜바다, 쿨엔조이. 회원들이 직접 발견해 올리고 추천/댓글로 검증.
2. **통합 사이트/봇**: 알구몬(algumon.com), 핫딜모음(hotdeal.zip) 등이 위 게시판들을 실시간으로 모아 주고 텔레그램 봇/채널로도 뿌립니다. 많은 핫딜 채널이 사실상 이걸 다시 옮깁니다.
3. **쇼핑몰 자체 특가 코너**: 쿠팡 골드박스(파트너스 API), 11번가 쇼킹딜/타임딜, G마켓 슈퍼딜, 네이버 도착보장 특가, 토스 오늘의 특가, 올리브영 오늘드림 세일. API 가 있는 건 쿠팡뿐이고 나머지는 크롤링.
4. **제휴 네트워크 피드**: 애드픽 쇼핑메이트 핫딜 API, 링크프라이스 머천트 프로모션 피드. 이미 수익 링크가 붙어서 옴.
5. **다른 핫딜 채널/오픈채팅**: 텔레그램 채널은 사용자 계정으로 읽어 재가공 가능(카톡은 불가).

우리 봇은 1(뽐뿌), 2(알구몬), 3(쿠팡 API), 4(애드픽) 를 지원하고, 5(텔레그램 채널 읽기)는 다음 단계 후보입니다.

## 판정 순서 (2026-09 기준)

1. **관심도 게이트**: 추천 ≥1 또는 댓글 ≥3 또는 조회 ≥500 (커뮤니티 글), 순위 ≤30 (쿠팡 API 목록) 중 하나라도 넘어야 판정 대상. 전 상품을 대조할 수 없어서 "사람들이 관심 있어 보이는" 딜만 본다. 수치는 `/ppstats` 분포를 보고 조정.
2. **(d) 시중가 대조 = 기본**: 다른 몰의 딜은 쿠팡 검색으로 같은 상품(수량 토큰 일치)을 찾아 비교. 20% 이상 싸야 특가, 대조 결과가 있는데 20% 미만이면 탈락(`market.strict`).
3. 대조 결과가 없을 때만 보조 규칙: (b) 30일 평균가 대비 15%↓, (c) 추천 ≥5, (a) 표시 할인율 ≥50% (서브 신호, 점수 절반 가중).
4. `/hot` 으로 지금 추천 N개 이상인 글 목록을, `/find 키워드` 로 특정 상품이 어느 소스에 언제 처음 보였는지 확인할 수 있다.

## 시중가 대조가 어려운 이유와 우회

- 네이버 쇼핑 검색 API(가격비교 최저가)는 2026년 7월 31일 종료되어 쓸 수 없습니다. 다나와·에누리는 API 가 없고 크롤링을 막습니다.
- 그래서 봇은 **쿠팡 검색 API** 를 시중가 기준으로 씁니다. 토스/네이버/11번가 딜의 상품명으로 쿠팡을 검색해 같은 상품(수량 토큰 일치)의 최저가와 비교합니다. 쿠팡 API 는 시간당 호출 제한이 빡빡해서(검색 기준 10회) 후보 딜에만, 시간당 3회까지만 조회하고 결과는 24시간 캐시합니다.
- 쿠팡 딜 자체는 다른 몰과 비교할 기준이 없어, 쿠팡의 표시 할인율 대신 **봇이 쌓은 30일 가격 이력**으로 판단합니다.

토스쇼핑은 앱 전용이라 "토스 앱 안의 특가 목록"을 직접 크롤링하는 방법이 없습니다. 대신 뽐뿌·루리웹 같은 커뮤니티에 올라오는 `[토스쇼핑]` 글을 수집하고, 내가 앱에서 쉐어링크를 만들어 붙이는 방식입니다.

## 서버 비용

월 1만원 예산이면 충분합니다. 오라클 클라우드 Always Free(0원) 로 시작하고, 부족하면 Railway Hobby(월 5달러) 로 옮기면 됩니다. 봇 자체는 메모리 200MB 이하로 돕니다.
